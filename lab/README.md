# Математическая лаборатория — локальная версия

Откройте `index.html` в Chrome или Edge. Это входная страница с тремя направлениями и работающими переходами к материалам.

Для переноса сохраняйте вместе папки `lab` и `trainers`, лежащие рядом. Новые страницы используют относительные пути, соответствующие будущим адресам `/lab/` и `/trainers/`.

Основные тренажёры и модели скопированы для просмотра. Их исходники в Яндекс Диске не менялись. Страница сайта и публикация на GitHub не изменены.

Некоторые существующие материалы используют внешние библиотеки и шрифты: для полного просмотра нужен интернет.

В каталог включена базовая коллекция стереометрии alpha. Вторая версия учебных сценариев остаётся в исходном проекте; её можно выбрать при следующем обсуждении.
